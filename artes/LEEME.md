# A&M · Boda

Logo tipográfico realizado con Parisienne Regular, convertida a curvas en los SVG para conservar el diseño sin instalar fuentes.

- AM-principal: verde oliva sobre fondo almendra.
- AM-oliva: verde #6E7F62, fondo transparente.
- AM-carob: marrón #725C3A, fondo transparente.
- AM-almendra: tono claro #E5E0D8, fondo transparente; para fondos oscuros.
- AM-negro: una tinta, fondo transparente; para sellos y producción monocromática.

Cada versión incluye SVG vectorial escalable y PNG de 3200 × 2000 píxeles. Para imprenta o corte, utilizar SVG. Para diseños digitales, utilizar PNG transparente. Mantener las proporciones y comprobar los trazos finos con el proveedor al fabricar piezas pequeñas.

Tipografía elegida por el usuario: https://www.1001fonts.com/parisienne-font.html
